# 六善愛心回收網站

這是一個純 HTML、CSS 和 JavaScript 網站，不需要安裝套件或執行建置程序。

## 上傳到新 GitHub repository

請把這個資料夾裡的所有檔案和 `assets/` 資料夾內容放在 repository 根目錄，確保 `index.html` 直接位於最外層，不要再多包一層資料夾。不要上傳 `sources/` 或本機設定檔。

## 發布前要改

- `site-config.js` 目前設定的 WhatsApp 號碼是 `85254790218`；發布前請確認這是要公開使用的號碼。之後要更換號碼，只改這個值即可，只填數字及國家區號。
- 在 `index.html` 更新聯絡電話、電郵和服務時間。

更新 GitHub Pages 發布分支後，GitHub 會重新發布靜態檔案。若網域網站仍由 GoDaddy 主機直接提供，還要把相同檔案同步到 GoDaddy 主機的網站根目錄，除非已設定自動部署。
